راهنمای فعال‌سازی برنامه هفتگی مدرسه

امکانات:
- مدیر: از manager.html > برنامه هفتگی، پایه/کلاس/روز/زنگ/درس/دبیر/زمان را ثبت یا ویرایش و حذف می‌کند.
- معلم: در teacher.html بخش «برنامه هفتگی» برنامه کلاس انتخاب‌شده را می‌بیند.
- دانش‌آموز: در student.html از صفحه خانه یا منوی کناری، «برنامه هفتگی کلاس من» را باز می‌کند. فقط برنامه پایه و کلاس خود را می‌بیند.

راه‌اندازی:
1) از مخزن GitHub فعلی خود نسخه پشتیبان بگیرید.
2) فایل school-panels-migration.sql را در Supabase > SQL Editor اجرا کنید (اگر قبلاً اجرا شده، می‌توانید دوباره اجرا کنید؛ اسکریپت از create if not exists و policyهای idempotent استفاده می‌کند).
3) فایل‌های index.html, manager.html, parent.html, student.html, teacher.html و messenger.html را در ریشه مخزن آپلود و Commit کنید. فایل school-panels-migration.sql را هم در مخزن نگه دارید.
4) پس از انتشار، با حساب مدیر یک برنامه آزمایشی ثبت کنید و سپس با حساب دانش‌آموز همان کلاس و حساب معلم دارای همان کلاس بررسی کنید.

نکته امنیتی: کلید publishable سمت مرورگر برای Supabase مناسب است؛ هرگز service_role/secret key را داخل HTML قرار ندهید. نمایش برنامه به policyهای RLS در فایل SQL وابسته است.

نسخهٔ بازطراحی‌شدهٔ سایت و پیام‌رسان
---------------------------------
- فایل‌های HTML این بسته ظاهر هماهنگ‌تر و رابط کاربری تازه‌تری دارند.
- صفحهٔ ورود دیگر دکمهٔ پیام‌رسان ندارد. لینک پیام‌رسان فقط پس از ورود موفق و تأیید نقش حساب در پنل‌ها نمایش داده می‌شود. باز کردن مستقیم messenger.html بدون نشست ورود، کاربر را به صفحهٔ ورود برمی‌گرداند.
- پیام‌رسان دارای فهرست کانال‌ها، جست‌وجوی کانال، حباب‌های پیام، کادر ارسال مناسب موبایل و پنجرهٔ اعلان‌هاست.
- برای اینکه پیام‌رسان به پایگاه داده وصل شود، اگر قبلاً فایل messenger-migration.sql را در Supabase اجرا نکرده‌اید، آن را یک‌بار اجرا کنید. اگر اجرا شده و جدول‌ها سالم هستند، نیازی به اجرای مجدد نیست.
- پس از خارج کردن فایل ZIP، فایل‌های index.html، manager.html، parent.html، student.html، teacher.html و messenger.html را در ریشهٔ مخزن GitHub بارگذاری و Commit کنید. فایل‌های SQL را هم نگه دارید.
